# Public dataset provenance

`orders.csv` is an original, synthetic 12-row e-commerce order dataset dedicated to **CC0 1.0** (https://creativecommons.org/publicdomain/zero/1.0/). It contains no real customer information. The `customers` are synthetic codes, not personal information.

The source is a small reproducible demo of inserts, updates, deletes and data quality. It is not an external industry benchmark. Production-scale evaluation needs separate licensed datasets and volume testing.
